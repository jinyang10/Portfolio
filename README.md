## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deploy

Pushing to `main` runs `.github/workflows/pages.yml` and deploys to GitHub Pages.
